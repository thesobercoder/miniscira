# Social pulse

Follow this when the user wants the mood, reactions, or community opinion rather
than authoritative facts.

## 1. Frame

- Identify the subject and what signal matters: overall sentiment, specific
  praise/complaints, breaking reactions, or an ongoing debate.
- Note the time window and state the date; reactions are time-sensitive.

## 2. Gather both channels (in parallel)

- **`x_search`** — real-time reactions, announcements, and expert/insider takes.
  Pass 3–5 query variations; scope by date or handles when relevant. If the user
  shares a post link, put it as the first query.
- **`reddit_search`** — deeper opinions, lived experiences, and community
  consensus, with subreddit context. Use a time range for recency.
- Read the actual posts and threads. Don't infer sentiment from counts alone.

## 3. Synthesize the vibe

- Lead with the overall sentiment in 2–3 sentences (positive / negative / mixed,
  and why).
- Break out the main themes (what people praise, criticize, or argue about),
  each backed by representative posts.
- Quote or tightly paraphrase a few standout posts (with the @handle or
  subreddit). Separate widespread views from fringe or outlier takes.
- State the limits plainly: X and Reddit are vocal, self-selected communities,
  not a representative survey.

## 4. Cite

- Link each post or thread inline with `[@handle or title](https://…)`. Only cite
  posts you actually retrieved via `x_search` / `reddit_search`. Never fabricate.
